# Gerador de Tabuada

Aplicação web de estudo que recebe um número e um limite e monta a tabuada dinamicamente no navegador.

## Funcionalidades

- definição do número base;
- definição do multiplicador máximo;
- geração das operações com JavaScript;
- atualização dinâmica da área de resultados.

## Tecnologias

HTML5, CSS3, JavaScript, DOM e eventos de formulário.

## Execução

Abra o arquivo `index.html` no navegador.
